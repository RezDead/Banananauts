# Banananauts

Banananauts is an Unreal Engine 5 game created for a Chico State video game production course. 

The necessary software for this repo is:
* Unreal Engine 5
* Visual Studio Community 2022

The game itself is a first-person comedic physics-construction game about a monkey building a spaceship to get to the Sun.
